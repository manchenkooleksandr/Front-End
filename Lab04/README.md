# ЛР №4. Доступ до DOM

Манченко Олександр Віталійович, ІО-41. Варіант 76, елементи 7 і 8.

З цієї папки виконайте:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Відкрийте http://127.0.0.1:8000. Натисніть на пункти «Міська фотографія» та «Настільні ігри». Виконайте додавання, зміну ширини та видалення фото.
