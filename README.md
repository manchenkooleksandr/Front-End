## GitHub Pages

Демонстрації зібрані на [сторінці лабораторних](https://manchenkooleksandr.github.io/Front-End/). Гілка `gh-pages` містить файли для публікації й готову збірку ЛР №7.

Щоб зібрати сайт локально, виконайте `bash scripts/build-pages.sh dist` у корені репозиторію. Потрібні Node.js і npm. Скрипт створює новий вихідний каталог.
