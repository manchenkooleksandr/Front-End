# ЛР №7. React і галерея товарів

Манченко Олександр Віталійович, ІО-41. Варіант 76, елементи 7 і 8.

З цієї папки виконайте:

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

Відкрийте http://127.0.0.1:5173. Перевірте два інтерактивні елементи, чотири кнопки фото і шість карток товарів. Для локального показу побудованого сайту використовуйте npm run preview.
