З цієї папки виконайте:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Відкрийте http://127.0.0.1:8000. Заголовки, метатеги, два списки, опис Києва, фото і посилання на сайт міста. Біографічний зміст демонстраційний.
