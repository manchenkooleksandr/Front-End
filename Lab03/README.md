З цієї папки виконайте:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Відкрийте http://127.0.0.1:8000. Два макети відтворюють ту саму геометрію. Зменште ширину екрана до 512 px, щоб побачити перехід нижньої пари у вертикальну колонку.
