# ЛР №8. Адаптивна верстка за макетом

Манченко Олександр Віталійович, ІО-41. Варіант 16.

З цієї папки виконайте:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Відкрийте http://127.0.0.1:8000. Перевірте головний екран, шість напрямів, чотири показники, три курси та чотири профілі. За ширини до 48 rem головний блок стає одноколонковим.
